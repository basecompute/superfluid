# superfluid 0.1.14

**`superfluid serve` uses speculative decoding by default for BaseRT
models.** A BaseRT model served with no `--speculate` now serves as if
`--speculate auto` were given, drafting with the drafter the catalog pairs
with it or with the MTP head in its file. `--speculate off` serves it plainly,
as no flag did before. llama.cpp and MLX models stay plain by default.

## Changed

- **Speculative decoding by default on BaseRT.** With no `--speculate`, a
  BaseRT model drafts with its paired drafter, or with its own MTP head, or
  decodes plainly when it has neither. This holds for the first model, for
  the others given at startup, and for models loaded later through
  `--model-dir` or `/v1/models/load`, including with a pinned installation
  (`--runtime basert@<install>`). As with a hand-given `auto`, a paired
  drafter that is not installed is downloaded first: on a Mac, 1.4 GB for
  Qwen3.8-27B's DFlash2 drafter and 458 MB for Qwen3.6-35B-A3B's.
  `--offline` downloads nothing. With speculation on, greedy output is not
  always word for word the plain output unless `--spec-bitexact` is set,
  and the automatically sized context window leaves room for the drafter,
  so a benchmark of plain decoding needs `--speculate off`. llama.cpp and
  MLX models are unchanged: their `auto` is prompt-lookup, which stays
  opt-in. See
  [speculative decoding](https://github.com/basecompute/superfluid/blob/v0.1.14/docs/features/speculative_decoding.md).

The engine ABI is unchanged: superfluid 0.1.14 serves BaseRT 0.5.1,
released alongside, and the 0.5 and 0.4 releases as 0.1.13 does. BaseRT
0.5.1's `basert serve` already starts superfluid with `--speculate auto`, so
this release matters when you run `superfluid serve` yourself.

See [installation](https://github.com/basecompute/superfluid/blob/v0.1.14/docs/getting_started/installation.md)
for every way to install superfluid, and
[updating](https://github.com/basecompute/superfluid/blob/v0.1.14/docs/serving/updating.md)
for how each is updated.
