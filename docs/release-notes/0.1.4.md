# superfluid 0.1.4

**baseRT models can be pulled by file name.** `superfluid serve` takes
`--pull-file <name>` for a baseRT model, to serve one `.base` from a repository
that holds several, such as one whose files are named by size rather than by
quant:

```sh
superfluid serve basecompute/Qwen3.8-27B-BaseQuant-V1 --pull-file Qwen3.8-27B-BaseQuant-V1-Medium.base
```

## New

- `--pull-file <name>` for baseRT models, passed to `basert pull --file`. The
  `.base` extension is optional, and a name several directories share is given
  with its path. It needs basert 0.4.1 or later.

## Fixed

- `superfluid runtime install basert`, and a `serve` that installs the baseRT
  engine first, take the newest baseRT release this build serves. They took
  0.3.0, and a newer release only with `--sha256`, so `--pull-file` failed on
  a fresh install.

See [supported models](https://github.com/basecompute/superfluid/blob/v0.1.4/docs/models/supported_models.md)
for every runtime's pull options.
